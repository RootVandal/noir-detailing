# NOIR DETAILING — концепт сайта детейлинг-студии (Алматы)

Демонстрационный сайт для показа клиенту. Чистый HTML/CSS/JS, без сборки и зависимостей.

## Запуск

```bash
python -m http.server 8802
```

Открыть http://localhost:8802

## Как поменять бренд

Всё, что связано с брендом, лежит в `config.js` → `window.BRAND`:

| поле | что меняет |
|---|---|
| `name`, `suffix` | логотип, `<title>`, огромное слово в футере, копирайт, текст заявки в WhatsApp |
| `tagline`, `city`, `since` | подписи в hero |
| `phone`, `whatsapp`, `email`, `instagram`, `telegram` | все ссылки связи |
| `address`, `addressNote`, `hours`, `mapQuery` | футер и кнопка «Открыть в 2ГИС» |

## Контент

- `SERVICES` — 4 направления (тексты, состав работ, срок, цена «от», фото).
- `CARS` — работы. Каждая машина получает свою страницу `#car/<slug>`: галерея с лайтбоксом, характеристики, замеры, слайдер «до/после», список услуг, переход к следующей работе.
- `CAR_CLASSES`, `CERAMIC_LEVELS` — коэффициенты калькулятора.
- `FAQ` — вопросы.

Фото — Unsplash (подгружаются по id через `IMG(id, width)`). Для боевой версии заменить на реальные снимки студии; слайдер «до/после» сейчас имитирует эффект фильтрами — туда нужны настоящие пары фото.

Форма записи — демо: проверяет поля, форматирует телефон и собирает сообщение для WhatsApp, на сервер ничего не отправляет.
